# Rides

Daily ride counts for a fixed set of cities, summarised on a static dashboard.

## Language

**City**:
A place whose rides are counted separately in the data.
_Avoid_: Market, region, location

**City's rides for a day**:
The number of rides counted in one city on one date; one row of the data.
_Avoid_: Daily rides, daily count

**Daily total**:
The number of rides across all cities on one date.
_Avoid_: Daily rides, rides per day
